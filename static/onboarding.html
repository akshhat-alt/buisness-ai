Manual Cloud API Setup Checklist (~10 minutes):
  1. Meta App & WhatsApp Product: In Meta for Developers → My Apps, create a Meta App (type: Business) and add the WhatsApp product to it.
  2. Phone Number ID: Under WhatsApp > API Setup in your Meta App, add or select your phone number. Copy the numeric Phone Number ID (not the phone number itself).
  3. Permanent Access Token: In Meta Business Settings → System Users, create a System User, assign your WhatsApp account asset with the whatsapp_business_messaging permission, and generate a permanent access token (for quick testing, you can also copy the temporary 24-hour access token from the API Setup page).
  4. Save Connection: Paste your Phone Number ID and access token into the fields below and click Save Connection.
  5. Message your number: Message that WhatsApp number from any phone — your assistant will answer from your ingested knowledge base within seconds!
