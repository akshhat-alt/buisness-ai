            WhatsApp Assistant

            Let customers message your assistant directly on WhatsApp — same business info, same lead capture, same complaint alerts as the website chat.

            Want help connecting WhatsApp?

            Leave your number — we'll set up your Meta Cloud API and number with you, no technical steps required.

            Free Setup Concierge
            I'll do it myself (advanced)
            Manual Cloud API Setup Checklist (~10 minutes):
            1. Meta App & WhatsApp Product: In Meta for Developers → My Apps, create a Meta App (type: Business) and add the WhatsApp product to it.
            2. Phone Number ID: Under WhatsApp > API Setup in your Meta App, add or select your phone number. Copy the numeric Phone Number ID (not the phone number itself).
            3. Permanent Access Token: In Meta Business Settings → System Users, create a System User, assign your WhatsApp account asset with the whatsapp_business_messaging permission, and generate a permanent access token (or temporary test token).
            4. Save Connection: Paste your Phone Number ID and access token into the fields below and click Save WhatsApp Connection.
            5. Message your number: Message that WhatsApp number from any phone — your assistant will answer from your ingested business info within seconds!

            Deposits & Win-Back

            Two separate, optional tools — set up only the ones that fit your business. Neither does anything until you fill it in and save.

            1. Booking Deposits Optional

            For businesses that take advance bookings (salons, clinics, event spaces): your assistant can send a customer a deposit-payment link on WhatsApp to reduce no-shows. Money goes straight into your own Razorpay account — Bizistic never holds it. Leave this blank if you don't take deposits. Find your Key ID/Secret under Razorpay → Settings → API Keys.

            2. Customer Win-Back Optional

            For repeat-visit businesses (salons, restaurants, gyms): a regular customer who hasn't messaged or visited in a while automatically gets one warm "we miss you" WhatsApp nudge — never spammed, sent once per gap.
